
# REMEMBER ME
# Description
its the infamous SIMON game made in arduino using 4 buttons, 4 leds and a buzzer.

# Schematic
the arduino uno already has an internal pullup resistor, so we use it. if your board doesnt come with an internal pull up resistor you will have to put them externally to make it work!
